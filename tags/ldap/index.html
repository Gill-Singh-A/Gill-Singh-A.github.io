Extracting Passwords in Plaintext by Sniffing LDAP Bind Requests

LDAP Servers on Network I decided to investigate the LDAP servers within my institute’s private network, which utilizes Class B private IP addresses. I employed Gill-Singh-A/Port-Scanner to scan for LDAP ports (389, 636, 3268, 3269) and discovered 49 devices with at least one of these ports open. LDAP Anonymous Bind Following that, I used Gill-Singh-A/LDAP-Anonymous-Bind-Checker to assess LDAP Anonymous Bind support, finding that 32 devices allowed anonymous binding. After some exploration, I discovered the LDAP server responsible for managing authentication requests for our Computer Center’s credentials.
